Этот шаблон уже настроен для развертывания на Netlify. Файл `netlify.toml` в корневом каталоге проекта автоматически задает команду сборки, директорию для публикации и заголовки безопасности.

## Пошаговый процесс развертывания

### 1. Отправка кода в GitHub

Если вы еще этого не сделали, создайте репозиторий на GitHub и отправьте в него свой проект:

```bash
git init
git add -A
git commit -m "Initial commit"
git remote add origin https://github.com/your-username/your-repo.git
git push -u origin main
```

### 2. Подключение к Netlify

1. Войдите в свою учетную запись на [Netlify](https://app.netlify.com).
2. Нажмите **Add new site** («Добавить новый сайт»), а затем — **Import an existing project** («Импортировать существующий проект»).
3. Выберите нужный репозиторий GitHub.
4. Netlify автоматически определит параметры сборки из файла `netlify.toml`.
5. Нажмите **Deploy site** («Развернуть сайт»).

### 3. Привязка собственного домена

После развертывания перейдите в раздел **Domain management** («Управление доменами») в панели управления Netlify и добавьте свой домен. Netlify автоматически предоставит бесплатные HTTPS-сертификаты.

### 4. Обновление URL-адреса сайта

После привязки домена обновите поле `site` в файле `astro.config.mjs` и поле `url` в файле `src/data/siteData.ts`, указав ваш рабочий (production) URL-адрес. Это гарантирует, что карты сайта (sitemaps), канонические URL-адреса и структурированные данные будут указывать на верный ресурс.

## Форма обратной связи

Форма обратной связи использует функционал Netlify Forms, который начинает работать автоматически сразу после развертывания сайта на платформе. Дополнительная настройка не требуется — все отправленные через форму сообщения будут отображаться в панели управления Netlify в разделе **Forms**.

## Непрерывное развертывание (Continuous Deployment)

При каждом обновлении основной ветки (main branch) вашего репозитория Netlify будет автоматически выполнять повторную сборку и развертывание сайта. Обычно процесс сборки занимает менее 5 секунд. Вот и всё — ваш сайт запущен!
