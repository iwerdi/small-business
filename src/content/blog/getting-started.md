Добро пожаловать на сайт вашего малого бизнеса! Этот шаблон поможет вам быстро запустить профессиональный веб-сайт, оптимизированный для мобильных устройств, который загружается менее чем за секунду.

## Быстрая настройка

1. Клонируйте репозиторий.
2. Выполните `pnpm install` для установки зависимостей.
3. Запустите `pnpm dev`, чтобы включить сервер для разработки.
4. Откройте `http://localhost:4321` в браузере.

## Настройка информации о компании

Все необходимые данные собраны в одном файле: `src/data/siteData.ts`. Откройте его и укажите название вашей компании, номер телефона, адрес электронной почты, физический адрес, перечень услуг, отзывы и информацию о членах команды.

## Изменение внешнего вида

- **Цвета и радиусы скругления** — редактируйте файл `src/styles/theme.css` (блок `@theme`). Это основной источник настроек: Tailwind автоматически генерирует на его основе служебные классы (utility classes).
- **Шрифты** — обновите названия шрифтов в файле `src/config/brand.ts`, а также массив `fonts` в конфигурационном файле `astro.config.mjs`.

## Добавление изображений

Разместите свои фотографии в соответствующих папках внутри `src/assets/images/`:

- `hero/` — главное изображение для домашней страницы.
- `about/` — фотография вашей команды или рабочего пространства.
- `gallery/` — снимки выполненных проектов (в любом количестве).

Затем обновите файл `src/config/images.ts`, указав пути к новым файлам. Пока вы не добавите собственные изображения, в шаблоне будут отображаться заглушки.

## Развертывание (Deployment)

Шаблон уже настроен для работы с платформой Netlify. Загрузите свой репозиторий на GitHub и подключите его к Netlify — файл `netlify.toml` возьмет на себя все остальное.
